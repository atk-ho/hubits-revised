# HUBITS: Revised v0.2.0 — Solo-first offline prototype

Upload the **contents** of this folder to the root of your GitHub Pages repository (not the enclosing folder). Open the published site once online to cache it for offline play.

## Included
- Mobile portrait and landscape coding arcade
- Offline profiles (new v0.2.0 storage namespace)
- Python / JavaScript Story stages, plus prototype Endless, Custom and Daily modes
- 6 × 10 falling board, one block removed per correct answer, gravity
- Tap-to-activate buffs, safe 15-second start, timed solo hazards
- Synthesized chiptune and sound effects with volume settings
- End Game confirmation and results overlay

## Important limitations
- This is an **offline prototype**, not online multiplayer or a full programming interpreter.
- Questions are curated multiple-choice exercises; Stage progression uses a shared question pool.
- Daily and Custom are simplified solo variations, not fully configured systems.
- v0.1.x profile saves are intentionally **not imported**. Export old backups before updating.
- Browser local storage may be lost if site data is cleared; use Profile > Export save backup. Backup restore is not yet implemented.
- Music starts after a user interaction due to mobile browser policies.
